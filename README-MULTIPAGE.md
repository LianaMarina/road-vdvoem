# Дорога вдвоём — многостраничная версия

## Размещение на GitHub Pages
Загрузите **все** файлы из ZIP в корень репозитория (ветка main, /root), а не только index.html. Если раньше был один HTML-файл, старые дополнительные файлы можно оставить; главное — новый index.html и все новые страницы.

- index.html — главная страница с выбором этапа
- russia.html — Россия до Владикавказа
- georgia.html — две границы и Грузия
- turkey.html — Турция и варианты ночёвки Хопа/Трабзон
- budget.html — действующий финансовый дневник
- diary.html — действующий дневник фотографий и историй
- site.css, stage.js — общие стили и интерактивные карты этапов
- config.js, supabase-setup.sql — оставлены для будущей облачной синхронизации

Бюджет и дневник по-прежнему используют те же localStorage-ключи, что и предыдущая версия. **Данные привязаны к браузеру и домену**, поэтому сохранятся при обновлении на том же домене, если их не удаляли. Для резервного копирования используйте экспорт JSON. Синхронизация телефонов ещё не настроена.

Маршруты на картах схематичные, не пошаговые автомобильные дороги. Поставщик тайлов может использовать названия на разных языках. Если один источник не отвечает, есть резервный.

## Обновление маршрута через Грузию
Грузия — транзит без запланированной ночёвки в Тбилиси. Первая ночёвка после Владикавказа — Хопа или Трабзон, в зависимости от границы и усталости. Старые ключи бюджета для Грузии оставлены для совместимости с ранее сохранёнными расходами.
